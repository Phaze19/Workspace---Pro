# Workspace---Pro

1.1 Overview:
WorkSpace Pro is a web-based office resource management system developed as part of the Web Programming Laboratory mini project. The system is built using a standard LAMP-style stack — HTML, CSS, JavaScript, PHP, and MySQL — and is designed to manage desks and meeting rooms in a modern hybrid workplace environment.

The project demonstrates the practical application of core web programming concepts
including server-side scripting with PHP, relational database design with MySQL, session-
based authentication, role-based access control, and full CRUD (Create, Read, Update,
Delete) operations across multiple user types.

1.2 Motivation
Modern offices increasingly operate on hybrid work models where employees do not have
permanent desks and share resources such as meeting rooms and workstations. Without
a centralized system, this leads to desk squatting, double-booking of rooms, and poor
visibility into which spaces are available. WorkSpace Pro addresses all of these problems
through a structured, role-aware booking and management platform.


1.3 Objectives
The key objectives of this project are:
• To design and implement a multi-role web application with three distinct user types.
• To implement secure authentication using PHP sessions and password hashing.
• To build a relational MySQL database with foreign key constraints and referential
integrity.
• To implement server-side conflict detection to prevent double-booking of resources.
• To provide a clean, responsive user interface using plain HTML, CSS, and JavaScript.
• To cover all four CRUD operations for each user type in the system.
